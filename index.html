Get Started

This is a minimal static site. Follow the steps below to run it locally.

Prerequisites

  • Modern browser (Chrome / Edge / Firefox)
  • Optional: Python 3 or Node.js for a local server

Run locally (quick)

Using Python 3 (PowerShell):

python -m http.server 8000

Then open http://localhost:8000 in your browser.

Or with Node (if installed):

npm install -g http-server
http-server -p 8080

Development

  • Use the VS Code Live Server extension for live reload while editing
  • Save files and refresh to see changes

Deploy

Deploy to GitHub Pages, Netlify, Vercel, or any static hosting platform.

Troubleshooting

  • Port in use? try a different port (e.g., 8001)
  • Check browser console for 404s if assets fail to load
